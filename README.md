# Odin Recipes

A simple website showcasing various recipes as part of The Odin Project curriculum.  
This project helps me practice fundamental **HTML** skills, including:

- Structuring a webpage with semantic HTML
- Creating and organizing multiple HTML pages
- Using **anchor tags** (`<a>`) to link pages together
- Embedding **images** using the `<img>` tag
- Writing meaningful **commit messages** and managing versions with **Git**

## Future Improvements

- Implementing **responsive design** for mobile devices  
- Enhancing accessibility with proper **alt text** and semantic elements
